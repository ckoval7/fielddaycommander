How-To Guides

Step-by-step walkthroughs, grouped roughly in the order you'll need them. New to FD Commander? Start at the top.

Get the Server Running

Set up the computer FD Commander runs on and the network your stations connect to.

Prepare a Raspberry Pi

Use Raspberry Pi Imager to flash an SD card, set a hostname, configure Wi-Fi or Ethernet, and get your Pi online and ready for FD Commander.

SSH & Command-Line Basics

Connect to your Raspberry Pi over SSH, learn essential Linux commands, check on FD Commander, copy files with scp, and keep sessions alive with tmux.

Set Up a LAN for Field Operations

Build a reliable local network for your Field Day site with an off-the-shelf router. Covers giving the server a fixed IP, how clients find it, and keeping Wi-Fi alive next to the HF stations.

Plan Your Event

Create the event, then line up the bonuses and safety work before the weekend.

First Event Setup

Go from a fresh install to a fully configured Field Day event. Create the event, add equipment, configure stations, build the schedule, and invite operators.

Plan Your Bonuses and Objectives

Line up every Field Day bonus and Winter Field Day objective your club can earn, track them as they come in, and gather the proof before you submit.

Work Through the Safety Checklist

Walk the site with the Safety Officer or Site Responsibilities checklist, record who checked what, and earn the safety bonus.

Log Contacts

Get every station logging into the same log, from the browser or the logger your operators already use.

Set Up Multi-Station Logging

Run every Field Day station into a shared log on your LAN, from club computers, members' own laptops, or a mix, dupe checking across all stations, and a live score.

Set Up Station Mode

Bind a shared computer to its station, so operators can take turns by typing their callsign. No passwords needed.

Run the GOTA Station

Set up the Field Day GOTA station, sign in the coach, enter each new operator, and see how the GOTA and coach bonuses are scored.

Connect External Loggers

Send contacts from N1MM Logger+, WSJT-X, JTDX, and fldigi straight into FD Commander over UDP. Covers firewall ports, station matching, operator credit, and testing.

Digital Modes with fldigi

Work RTTY and PSK at Field Day: where to find signals, the exchange, a macro set to start from, logging with a few clicks, and sending each contact to FD Commander.

After Field Day

Send in your entry and keep a copy of everything.

Submit Your Field Day Entry

Review the score, download the Cabrillo log and submission sheet, gather the bonus proof, and send your entry to the ARRL.

Back Up and Restore

Schedule automatic backups of your log, photos, and settings, copy them off the server, and restore everything onto the same server or a new one.

Optional Extras

Only needed if you want email from the app or remote access over the internet.

Email Setup

Enable password resets, invitation emails, shift reminders, and notifications by adding SMTP credentials to your .env file.

DNS & TLS Setup

Point a domain name at your server and add HTTPS with Let's Encrypt. Only needed if you want to put FD Commander on the internet for remote access.
