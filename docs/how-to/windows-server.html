Install Field Day Commander on Windows

Set up the Windows server, then connect from a phone on the same network.

How-To Guides › Install Field Day Commander on Windows

Install Field Day Commander on a Windows computer, then let operators connect with a browser on the same network. They don't need to install anything on their phones, tablets, or laptops.

Choosing a Server

The Linux and Docker installs are recommended, especially for bigger clubs with many stations logging at once. Windows uses a simpler built-in database and is a supported option for clubs that only have a Windows computer to run the server on.

For the recommended options, follow the Linux install guide or the Docker instructions.

What You Need

  • A computer running 64-bit Windows 10 or 11, with administrator access.
  • The Windows server installer from a GitHub release.
  • A phone, tablet, or laptop on the same network to check access.

Everything the server needs comes in the installer, so you don't need Linux or Docker. Once you've downloaded it, you don't need internet access to install or run the server.

Step 1: Download the Installer

Open the GitHub releases page and look for the Windows server assets. Download field-day-commander-server-setup-<version>.exe. The release also includes field-day-commander-server-setup.sha256 with the installer's checksum.

The installer isn't code-signed, so Windows SmartScreen may show “Windows protected your PC”. Click More info, then Run anyway to continue.

Step 2: Run the Installer

On the Windows computer that will run the server, open the downloaded installer and approve the administrator prompt. Read the welcome and GPL license pages, then continue with the installation.

During setup, you'll see Setting up the server and Windows services. This takes a minute or two... Leave the installer open until it finishes.

Step 3: Read the Finish Page

The finish page says that Field Day Commander is running and will start whenever this computer starts. Write down the address shown for operators. It uses the computer's name, such as http://shack-pc.local.

The installer tries web port 80 first, then 8000, then 8001. If it uses a port other than 80, the address includes it, such as http://shack-pc.local:8000. Keep that port in the address you share.

Leave Open Field Day Commander on this computer checked to open the site through http://localhost, with the selected port if needed.

Step 4: Set the Administrator Password

The first visit opens the setup wizard. Fill in Set Admin Password and Confirm Password, then complete the site branding and preferences pages. Save the password somewhere safe. When setup finishes, sign in with admin@localhost and that password.

First Event Setup walks through the wizard and setting up your event.

Step 5: Check From a Phone

Connect your phone to the same network as the server and open the operator address from the finish page. You should see the site. Use that address for your operators, rather than localhost, which refers to the device opening it.

The .local address depends on name resolution on your network. If it doesn't work, use the server's local IP address with the same web port.

Back Up and Restore

In the Start menu's Field Day Commander folder, open Back Up Field Day Commander. Approve the administrator prompt. The tool makes a zip containing the database, uploaded photos and files, and the app key and mail settings needed on a new server. When it finishes, it offers to show the file in Explorer. Copy it to another computer or a USB drive.

Open Field Day Commander Backups in the same Start menu folder to see saved backups. They're stored in C:\Users\Public\Documents\Field Day Commander Backups.

Automatic backups are enabled during installation. They run hourly while an event is in progress and daily at 03:00 otherwise. The newest 48 automatic backups are kept. Backups you make yourself aren't pruned.

Automatic backups leave out uploaded files

Automatic backups contain the database and settings, without photos or other uploaded files. Use the Start menu backup tool when you want those files included.

To restore, open Restore Field Day Commander from a Backup and approve the administrator prompt. Choose a backup and review the contents shown before confirming. The tool stops the services, saves the current data as a “backup before restore,” restores your backup, and starts the services again. Operators can't log during the restore. To undo it, restore the “backup before restore” file.

Backups from a newer version and damaged databases are refused before your data changes. If a backup came from a newer release, upgrade the server before restoring it.

Upgrade or Uninstall

To upgrade, run the newer installer on the same computer. It stops the services and replaces the code while keeping your data, settings, and web port.

To uninstall, remove Field Day Commander Server from Windows' installed apps. The uninstaller asks whether to also delete your log, settings, and photos. No is selected by default. If you keep the data, reinstalling will use it again. Backups in Public Documents are always kept.

Troubleshooting

Setup says it could not finish

Read C:\ProgramData\Field Day Commander\logs\setup.log for the error. Fix the problem described there, then run the installer again.

Ports 80, 8000, and 8001 are all in use

Close a program using one of those ports, then run the installer again.

The site opens on the server but not on a phone

Check that both devices are on the same network and that you're using the address from the finish page, including its port. Try the server's local IP address if its .local name doesn't resolve.

The installer adds firewall rules in the Field Day Commander group for the web server and TCP and UDP logger listeners. They allow connections from the local subnet on every network profile, including Public. Live updates go through the web port, so you don't need to open a separate WebSocket port.
